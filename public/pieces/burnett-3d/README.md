# Burnett 3D piece set (shaded variant of the Burnett set)

Bold-outline pieces after Colin M. L. Burnett's "cburnett" set (the default set
on Lichess). The original artwork is by Colin M. L. Burnett and is available
under CC BY-SA 3.0, GFDL and GPLv2+ (see https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces).
These files are derived from it; if you redistribute them, keep this credit and
the same licence terms. If you prefer the official files, drop them over these
twelve (`wK.svg` … `bP.svg`) unchanged.
