## Game history database

Finished games (and any game opened with **Analyze**) are stored in Postgres
through Prisma, and listed on the **History** page.

```bash
docker compose up -d          # local Postgres (or point DATABASE_URL at your own)
cp .env.example .env          # DATABASE_URL for the container above
npm install                   # also runs `prisma generate`
npm run db:migrate            # creates the Game table
npm run dev
```

On a server, run `npm run db:deploy` instead of `db:migrate`. There are no user
accounts yet, so anyone who can open the app can save and delete games; add
authentication in `app/actions/games.ts` before putting it on the public web.
